1. What is CSS?

CSS stands for Cascading Style Sheets. It is a stylesheet language used to control the presentation and appearance of HTML elements.

2. Why do we use CSS?

CSS is used to style and design webpages. It controls colors, fonts, spacing, layouts, positioning, responsive design, and other visual aspects.

3. What are the three types of CSS?

The three types of CSS are Inline CSS, Internal CSS, and External CSS.

4. Which CSS type is preferred for large projects?

External CSS is generally preferred because it is reusable, maintainable, and keeps styling separate from HTML structure.

5. What does Cascading mean in CSS?

Cascading refers to the process CSS uses to resolve conflicts when multiple rules apply to the same element, considering factors such as importance, specificity, and source order.
